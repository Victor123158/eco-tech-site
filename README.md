# 🌍 Eco Tech - Site Institucional

Bem-vindo ao repositório do **Eco Tech**, um site dinâmico criado como parte da Avaliação III. Este projeto apresenta uma empresa fictícia focada em soluções sustentáveis.

## 📌 Funcionalidades
- Site composto por **3 páginas**: Home, Sobre e Contato.
- Desenvolvido com **HTML, CSS e JavaScript**.
- Layout responsivo para melhor experiência em dispositivos móveis.
- Publicado via **GitHub Pages**.

## 🚀 Como acessar o site
Clique no link abaixo para visualizar o site publicado:

## 🛠️ Tecnologias Utilizadas
- **HTML5** - Estrutura da página.
- **CSS3** - Estilização e layout responsivo.
- **JavaScript** - Interações dinâmicas.
